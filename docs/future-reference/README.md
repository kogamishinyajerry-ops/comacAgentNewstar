# 后续阶段参考区

当前开工包**有意不包含**完整参与者工作台、Artifact 管理、证据回流、评委打分和组织者态势中枢的概念图。

原因：这些强视觉资产会诱导阶段一提前膨胀为传统后台，破坏当前目标。

后续里程碑可以在此目录增加参考资料，但必须先更新：

1. `AGENTS.md` 的当前里程碑；
2. 新阶段开工提示词；
3. 权限、数据、真实后端与模型接口设计；
4. 对应的测试与验收标准。

在更新前，不得实现：

- 完整参与者工作台；
- 真实 Artifacts 管理；
- 外部构建任务执行；
- 证据上传与验证系统；
- 正式评委打分；
- 组织者统计 Dashboard；
- 排行榜、健康分或完成率驾驶舱。
