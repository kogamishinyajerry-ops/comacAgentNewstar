# UI 深度优化与 Image-2 资产接入 v0.1

## 目标

本轮针对验收中暴露的三项高优先问题进行增量整改，不扩张为完整产品重写：

1. 根入口缺少活动与用户旅程定向，首次访问者会在理解活动前直接被提问；
2. 第一问提前展示完整问题卡，削弱“一问一幕”和“工作空间由思考长出来”；
3. 公共 Hub 与受保护参与者工作区的前台语言不一致，旧工作区仍以完成率、十步健康度和段位为核心。

## 设计决定

### D1：根入口采用“定向层 + 立即实践”，而不是营销长页

根入口保留可直接作答的 Coach，但在工作台顶部增加一条极薄的活动定向层，快速回答：

- 这是什么：青年 AI Agent 创新实践月；
- 要做什么：把真实问题变成可验证的 Agent 作品；
- 会经历什么：三幕追问 → 问题种子 → 外部构建与证据回流；
- 下一步是什么：直接回答当前唯一问题，或打开活动指南。

这样既修复冷启动信息缺口，也不新增一次“看完官网再点击开始”的阻力。

### D2：空问题卡收成 68px 种子轨

第一问阶段不再提前展示 320px 完整问题卡，只保留一枚极弱的种子轨：

- 三个幽灵点暗示回答会被沉淀；
- 不展示表单式槽位正文；
- 第一份回答提交后，问题卡才扩展为完整上下文面板；
- 状态机、可访问名称、回看抽屉和响应式结构不变。

### D3：参与者工作区改为“主张—证据—缺口”

参与者首页移除前台的：

- 总体完成百分比；
- 进度环和进度条；
- “10 步健康度”；
- 段位与游戏化卡片。

替换为：

- 当前主张；
- 已接回的证据状态；
- 当前最大缺口；
- 一个最小下一步。

底层十步数据、提交规则和服务端进度引擎暂时保留，作为流程与治理基础，不再直接成为用户的视觉主模型。

### D4：评委入口强化人的独立判断

评委首页先强调“独立理解主张、证据与缺口”，再进入评分；AI 不预评分，也不在初判前制造锚定。当前数据库评分合同未在本轮修改。

## Image-2 资产

### `public/hub/art/hub-hero-cognitive-canvas.webp`

- 尺寸：1600×900；
- 用途：根入口活动定向层、参与者当前项目卡的低透明度背景；
- 语义：安静的认知画布、信息向问题种子收拢；
- 处理：纯装饰，`alt=""` 或 `aria-hidden`，不得承载业务事实。

### `public/hub/art/coach-state-listening.webp`

- 尺寸：768×768；
- 用途：替换 listening 状态插画；
- 语义：膜层向回答器方向轻微展开，表达“正在倾听”；
- 性能：体积显著小于旧资产；状态文字仍是唯一语义来源。

## 非目标

本轮没有伪装完成以下能力：

- 问题种子自动持久化为项目；
- 完整 Artifact 链；
- 外出构建任务包与证据回流；
- 评委 AI 第二意见与分歧校准；
- 组织者简报式管理中枢。

这些仍应按纵向闭环优先级在后续 PR 中实现。
