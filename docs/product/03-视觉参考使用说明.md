# 视觉参考使用说明

## 1. 参考图的地位

`docs/design-references/` 中的图片属于概念探索稿，只定义：

- 视觉气质；
- 信息层级；
- 留白关系；
- Coach 身份；
- 场景转场方向。

它们不是逐像素界面规格，也不是可直接切图上线的页面。

当图片与文字基线冲突时，以 `AGENTS.md`、阶段一开工提示词和产品执行基线为准。

## 2. 可以继承

- 安静、轻盈、可信的浅色认知画布；
- 深海军蓝主文字；
- 克制的钴蓝强调；
- 极少量淡紫、青色或琥珀状态信号；
- 抽象 AI Coach 光核；
- 大面积留白；
- 细线、弱边界和轻阴影；
- 单一视觉焦点；
- 信息逐个被“端上来”的节奏；
- Coach 从静候、倾听、质询、收拢到凝结的状态感。

## 3. 必须重构

参考图中的以下内容必须重新进行产品设计，不得机械复制：

- 左侧完整项目侧栏；
- 多栏专业工作台；
- 四到八个并列功能入口；
- 传统 Dashboard；
- 参赛者完成率、健康度和排名；
- 评委打分面板；
- 组织者统计大屏；
- 图片中的用户头像和真实感项目名。

当前阶段只做公共 Hub 与轻量 Coach 预览。

## 4. 禁止做法

- 将设计图设置为页面背景；
- 通过切图拼接冒充真实 UI；
- OCR 复制图片中的中文；
- 复制图片中的虚构数字、日期、分数或状态；
- 使用图片中的人脸作为真实用户头像；
- 从生成图中抠出并冒充官方 Logo；
- 用永久旋转、粒子雨或无意义发光模仿 Coach；
- 为了“像平台”提前实现大量空后台。

## 5. Coach 实现建议

优先使用 SVG + CSS + 状态驱动动画：

- 中央光源；
- 2–4 层半透明薄膜或轨迹；
- 极少量方向线；
- 轻柔阴影；
- 五种显式状态；
- `prefers-reduced-motion` 降级。

不要直接将光核截图作为核心交互对象。截图可以用于比对气质，生产 UI 应可维护、可响应和可访问。

## 6. 版式优先级

1. 当前问题；
2. Coach 状态；
3. 回答器；
4. 当前场景的少量上下文；
5. 次级导航与说明。

任何模块不得通过面积、数量、颜色或持续动画抢走当前场景的主导权。

## 7. 品牌说明

本开工包没有正式授权的 COMAC Logo 资产。

在正式品牌文件加入前：

- 使用纯文字活动标识；
- 或使用中性、非冒充官方标志的几何占位；
- 所有品牌资产从配置或 `public/brand/` 读取；
- 不从参考图中抠图。
