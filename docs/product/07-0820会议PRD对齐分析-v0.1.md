## 0. 一句话结论

PRD 的「网站」就是本仓库。参赛队核心动线（拷问智能体 → 问题卡片）与已交付的
新 Hub **几乎逐条吻合——PRD 对这一侧是「确认现状」，不是新需求**。真正的新增范围
集中在组织侧（3.5）、评委侧（3.6/3.10）与外部集成（3.9 工单/WorkBuddy/代码仓库），
它们与 `AGENTS.md` 现行里程碑边界（不做组织者仪表盘、评委评分系统、新后端）冲突，
执行前需分批授权（见 §5 与 `IMPLEMENTATION_PLAN.md` §30）。

## 1. 前提澄清：PRD 描述的就是本仓库

- pid 14「我实际上已经开发了一半了，一个问答的网页」+ pid 55「里面已经接入我的
  模型了」——指向本仓库新 Hub（`app/(hub)` 主入口 + `POST /api/hub/coach` 受控
  live 链路），**不是从零新建站点**。
- 仓库是双产品共存（README 已声明）：
  - **新 Hub `app/(hub)`**：三幕 Coach + 第四幕问题定义 Artifact，会话级、无 DB、
    无账号、剪贴板导出——阶段一/二及全部打磨轮的交付物；
  - **旧侧 `app/(app)`**：「青年AI轻创导航站」MVP 完整保留，含自建账号/角色
    （`lib/auth.ts`）、SQLite（prisma）、十步材料流 + 对话式工作台、评委端
    （四维 40 分）、组织者后台（配置/进展/项目/评审分配）、WorkBuddy 总控台
    （对话式动作注册表，`lib/control/` + `lib/workbuddy/`）。
- 因此对齐按三层展开：**新 Hub 已覆盖什么 / 旧侧已有什么 / 全缺什么**。
- PRD 的「三件套」定位（网页 + WorkBuddy 项目群 + 共享文件夹，pid 20）中，
  本仓库只承担「网页」一环；项目群与共享文件夹是外部系统（PRD §3.9 的集成对象）。

## 3. 已吻合项清单（零新工程或文案级）

以下 PRD 条目与现状一一对应，无需新增结构，只需在 PRD 复核时把「现状描述」
写成「已交付能力」：

1. **轮数**（pid 9「5–6 轮」↔ 三幕 + 三轮深化 = 6 问，`coach-machine.ts`
   `ACT_COUNT` + `ARTIFACT_ROUND_COUNT`）；
2. **一问一幕**（pid 57「每次只提一个最要紧的问题」↔ 产品宪法，98 e2e 守护）；
3. **三字段**（pid 57/67 ↔ 主张—证据—缺口，seedCopy `claim/evidence/gaps`）；
4. **末轮一次性生成**（pid 57 ↔ 客户端确定性合成，live 模型只填三字段，不编故事）；
5. **预设标准进系统提示词**（pid 15 ↔ §14 钢人思考纪律）；
6. **模型已接入**（pid 55 ↔ §28.3 probe 六用例 ALL PASS）；
7. **反模式清单同向**（PRD §五：不公开榜单 / 异步推进 / 智能体主动戳破「单轮
   问答机器人」↔ `AGENTS.md` 非协商项逐条同向，零冲突）；
8. **简化原则**（pid 68「拿简化版的几个指标让他们勾一下」↔ 无健康分、无完成率、
   证据用主张—证据—缺口表达的既有红线）。

## 4. 直接动代码的拍板项 ⚑

### ⚑D1 「证据」字段改名（PRD §九.1，严冬杰拍板）

候选：依据 / 影响 / 现状。**影响面不是换个标签**：贯穿 `fixtures/coach-demo.ts`
（seedCopy/artifactCopy）、`lib/hub/coach-provider.ts` 提示词与校验文案、
`artifact-card.tsx`、e2e 断言、`docs/product/01/02/05`。一旦拍板应单独成轮、
全链路一次改完；建议与 ⚑D3 的导出格式变更同轮，避免两次全量回归。

### ⚑D2 拷问口吻基线（PRD §3.2）

现状人格是「严格但建设性」的 AI Coach（`docs/product/02`）；会议口径是
「FDE 或业务专家，严苛」。修订属文案级（02 号规范 + 系统提示词措辞 + fixture
话术），**不触及三字段输出合同**，但人格规范是源头文档，需显式定稿。

### ⚑D3 问题卡可追述（PRD §3.3）

- **最小解（无 DB，P0 可做）**：导出文本内嵌「生成时间 + 六轮问答映射」；
- **完整解（队伍标识 + 时间戳落库）**：与「公共侧无 DB、会话即所得」宪法冲突，
  属持久化架构门（P2），须单独授权后设计。
